# SWC AI — Garbage Severity & Waste-Type Classifier

A complete, runnable deep learning microservice: upload a garbage/waste photo -> AI returns **LOW / MEDIUM / CRITICAL** severity + **ORGANIC / INORGANIC / MIXED** waste-type classification with confidence scores -> renders colored status banners.

---

## 🧠 Why YOLOv8-Classification (and not object counting)

- **Transfer learning:** `yolov8n-cls.pt` is pretrained on ImageNet. Fine-tuning adjusts the weights on your domain photos (`low/medium/critical` and `organic/inorganic/mixed`).
- **Scene-level judgment:** Classifies the **entire image** into actionable municipal categories without fragile manual object-counting loops.
- **Local & Real DL:** Runs 100% on PyTorch locally via `ultralytics` — no third-party API keys required at inference time.
- **Explainable Metrics:** Produces real Confusion Matrices, Top-1/Top-5 accuracy, and Precision/Recall/F1 numbers for judge reviews.

## 🚀 Quickstart Guide

### 1. Environment Setup (Anaconda / Windows)

```bash
conda create -n swc_ai python=3.10 -y
conda activate swc_ai
cd SWC_AI
pip install -r requirements.txt
```

### 2. Prepare & Train Models

```bash
# 1. Inspect raw datasets
python inspect_dataset.py

# 2. Build 80/20 train/val splits
python prepare_dataset.py
python prepare_dataset_type.py

# 3. Train both classifiers
python train.py
python train_type.py

# 4. Evaluate performance & generate confusion matrices
python evaluate.py
python evaluate_type.py
```

### 3. Run FastAPI Inference Server

```bash
uvicorn app:app --reload --host 0.0.0.0 --port 8000
```
Interactive Swagger API docs will be live at: **`http://127.0.0.1:8000/docs`**

### 4. Test Standalone UI

Open `SWC_AI/frontend/index.html` directly in any web browser to upload images and see live dual prediction banners.
